## Веб-интерфейс (`abook review`)

- Весь фронтенд — строка `REVIEW_HTML` в `abook` (+ вставки из `abook_ai_ui.py` по маркерам `/*AI:…*/`, `<!--AI:…-->`).
  Стиль — дизайн-кит cosmos-kit, копия в `kit/` (раздаётся сервером по `/kit/…`), правила — навык `.agents/skills/cosmos-site/SKILL.md`.
  Обновить кит: скопировать `src/` из репозитория кита в `kit/`, прочитать `kit/CHANGELOG.md` (пометки «ломает»).
- Сцена «чёрная дыра» одна на всё приложение (правило — навык, «Сцена в приложении и темп»). Главный экран — как демо кита:
  «витрина» (текст слева, дыра справа), настройки сцены по умолчанию, текстура `plate-hd.webp` (ESRGAN), −14 % экспозиции;
  открытая карточка живёт там же. Все остальные экраны — «ось» в темноте демо (`setScroll(1)`, ≈ 8 %, рендер на паузе).
  Переезд справа в центр — единственное движение сцены (пружина Apple: response 1,2 с, damping 0,85; уход: едет → гаснет,
  возврат: светлеет → едет). Герой и карточка отзыва — на одном левом датуме; карточка растёт до кольца (≤ 1180 px), от 840 px —
  две колонки, поле текста забирает высоту экрана — на 1920×1080 и 2560×1080 без прокрутки (прокрутка — только с цитатами).
  Поиск — оверлей сверху в колонке страницы, сцена только затемняется; Esc стирает запрос, второй Esc закрывает.
- Цвет: свет белый (`data-accent="white"`), дым нейтральный. Пока открыта карточка отзыва — дым «тёплый» из кита
  (при оценке ≤ 3 — «угольный»), поле текста золотое; шкала оценки — угли ≤ 3, золото 4–6, белое 7–10. Холодных цветов нет.
  Выбранное и «сделано» — без цвета (светлее плита, ярче кайма).
- Цитаты: несколько в одном поле `reviews.quote`, по абзацу на цитату (`splitQuotes`/`joinQuotes`); в файле для ИИ — строка
  «цитата:» на каждую. Статус копий (D:, облако, тестовая база) — панель «Сохранность» на экране «Проверка» (`paintSafety`).
- Кручение: долгий процесс (`procSet`/`procEnd`) раскручивает диск энергией и крутит знак-«катушку» в рельсе; сохранение
  отзыва — мягкий вздох `kick(k)` с долгим выбегом. Не на наведение и не по таймеру.
- UX — `kit/UX.md` (показывать всё, что помещается; ничего не плавает поверх полей; не больше 7 шагов; чернила по APCA —
  `python3 kit/tools/contrast.py`).
- ИИ-запуски (`abook_ai.py`): `initial`/`refresh` — профиль и топ-5 (`latest_run` читает только их), `plus1` — одна книга
  по тексту пользователя (`wish`), панель «+1 по запросу» в «Что дальше» (`paintPlus` в `abook_ai_ui.py`).

## Интерфейс — cosmos-kit

UI этого проекта — на дизайн-ките cosmos-kit (папка `kit/`, настройки — `cosmos.json`).
Любая задача про интерфейс — по навыку `cosmos-site` (`.agents/skills/cosmos-site/SKILL.md`): сам, до конца, без вопросов.

<!-- cosmos-top:begin -->
**10 правил, которые нельзя забыть** (коды — `python3 kit/tools/check.py --rules`; подробно — SKILL.md и `references/lessons.md`):
1. Сдано = строка `cosmos-done: OK` от `python3 kit/tools/cosmos.py done`. Нет строки — работа не сдана и отчёт не пишется.
2. `kit/` не правится (K1) и не читается целиком (`kit/css`, `kit/js`, демо): классы, токены, иконки — `check.py --classes|--tokens|--icons <слово>`.
3. Разметка — из `kit/blocks/` по `INDEX.md`; классы только существующие (H4); иконки `kit/icons/sprite.svg#i-…`, эмодзи нельзя (H6).
4. Своё — в `site.css`/`site.js` только на токенах `var(--…)`: без #hex, своих шрифтов, `@keyframes`, inline `style=`, `!important`, CDN (S1–S6, P5, J3).
5. Одна `.btn.primary` на экран, секцию и диалог (H1, B4); красная `.btn.solid.danger` — только в `<dialog>` подтверждения (H3); без `alert/confirm/prompt` (J1).
6. Текст читается в каждом состоянии (обычный, сделан, активный, наведение, фокус) и палитре: контраст ≥ 3:1; на заливке `--ink` цвет текста `--bg` (S10, B11).
7. Переключатель не двигает раскладку: позиция и высота соседей до и после одинаковы (±2px); место под переменный текст — `min-height` (B12).
8. Всё, что помещается, видно: ≤ 24 вариантов на широком экране (16 на узком), ≤ 7 шагов мастера, фильтры одним рядом, ничего поверх полей.
9. Тексты — результат и факт: кнопка «Создать плейлист», не «Отправить»; заголовок — утверждение; без клише и «Не X, а Y» (T1–T3).
10. После `done` глазами: снимки 2560×945, 1920×945 и 390 (и каждая палитра проекта: `shot.mjs --palette grey`), Tab по порядку, фокус виден, Esc закрывает.
