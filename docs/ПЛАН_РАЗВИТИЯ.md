# Аудиотека — план развития (26.09.2026)

## 1. Доделки
- Поле «Ваш запрос» у кнопки «Новый топ-5»; кнопка «Промпт для рекомендаций» (портрет + отзывы с весами + «Сейчас в фокусе» + запрос → копировать/скачать вместе с файлом библиотеки для любой LLM).
- Кнопка «Отменить» у проверок + подтверждение перед полной проверкой.
- Проверка порядка частей: не считать «16+/18+» номером; понимать смесь «Часть 2» и «книга I, часть III».
- Автоматический `fstrim` после каждого прохода скачивания.

## 2. Отправка в Telegram (главный способ слушать)
- Кнопка «В Telegram» у книги и «отправить следующие N из очереди» → Избранное или выбранный чат.
- От своего аккаунта через MTProto (Telethon): лимит 2 ГБ (4 ГБ с Premium). Bot API не подходит (50 МБ).
  Один раз: api_id/api_hash на my.telegram.org + вход по коду; сессия хранится локально.
- Большие книги — тома по главам ≤ 1,5–2 ГБ; длинные — части по 2–4 ч (в плеере Telegram нет глав).
- Подпись: автор, название, чтец, «часть 2/5», длительность, о чём, хештеги (#Кафка #Абсурд #Короткое). Обложка для .m4a.
- Отметка «отправлено», фоновая очередь с прогрессом, опционально бот-напоминание об отзыве.

## 3. Рекомендации
- Портрет «почему мне это нравится» и дрейф вкуса — по кнопке.
- Режимы: «на дорогу до 2 ч», «перед сном», «совсем новое».
- Цепочки «после этой книги».
- Внешний совет ИИ → «Добавить в библиотеку» (ресёрч → проверка → скачивание одной книги).

## 4. Библиотека
- Автопоиск замен для упавших/битых (Gemini → validate.py → скачивание) с отчётом.
- Фоновая выборочная ИИ-проверка (5 книг в неделю через abook-check).
- Дедупликация по отпечатку звука. VK (cookies) и Rutube.

## 5. Несколько людей
- Общая полка «рекомендую профилю X», сравнение вкусов, подборки «для двоих».
- Экспорт профиля (анкета + портрет + отзывы) одним файлом.

## 6. Упаковка
- `abook` в git-репозиторий с тестами и `uv tool install` (сейчас — большой живой файл + ручные правки: главный техдолг).
- Ярлык с иконкой вместо Отзывы.bat.
