# Аудиотека (abook) — установка и запуск на новом компьютере

Личная аудиотека с консультантом: ищет книги по каталогу из 180 тыс. записей (YouTube-каналы чтецов, knigavuhe,
akniga, archive.org, 4read, украинские каналы), даёт ссылку на источник, скачивает полную запись с проверкой
частей, склейкой и проверкой целостности, отправляет в Telegram, советует книги по вашему вкусу в чате.

Работает в Linux или WSL2 на Windows. Всё ставится без sudo, кроме системных пакетов из шага 1.

## 1. Что нужно заранее

| Что | Зачем | Как поставить |
|---|---|---|
| Python 3.10+ | сервер | есть в Ubuntu |
| ffmpeg, ffprobe | склейка и проверка аудио | `sudo apt install ffmpeg` |
| yt-dlp | скачивание | `pip install --user yt-dlp` или бинарь в `~/.local/bin` |
| git, gh | обновления, снимок каталога, синхронизация профилей | `sudo apt install git`, gh — https://cli.github.com, затем `gh auth login` |
| ИИ: Claude Code **или** Antigravity | чат, подбор, поиск | Claude Code: `npm i -g @anthropic-ai/claude-code`, затем `claude` и вход. Antigravity: CLI `agy` и вход |

Можно поставить оба ИИ — переключатель «Claude / Antigravity» в шапке чата и в «Настройке».

## 2. Установка

```bash
mkdir -p ~/projects && cd ~/projects
gh repo clone Ihor-Zakharov/abook          # приватный — нужен доступ
cd abook
./install.sh                                # ядро: запускалки в ~/.local/bin, папки ~/abook
./install.sh --desktop                      # ярлык «Аудиотека» на рабочем столе Windows (WSL)
# по желанию, можно позже:
./install.sh --vec                          # смысловой поиск (≈ 650 МБ)
./install.sh --tg                           # Telegram
```

## 3. Первый запуск — «Настройка» по шагам

`abook-ui` (или ярлык). Открывается браузер и мастер «Настройка». Любой шаг можно отложить.

1. **ИИ** — выберите Claude или Antigravity, «Проверить связь».
2. **Папка библиотеки** — куда класть книги, например `D:\Аудиокниги`. Временные файлы склейки пойдут рядом,
   а не на диск C:. После смены папки перезапустите приложение.
3. **Каталог** — «Скачать готовый каталог» (≈ 1 минута, снимок из релиза репозитория) или «Обойти источники
   заново» (≈ 2,5 часа в фоне).
4. **Ваш вкус** — анкета по шагам или «Рассказать своими словами».
5. **Telegram** — необязательно. Сначала можно без него.
6. **Другие компьютеры** — синхронизация профилей через ваш приватный репозиторий `abook-data`.

## 4. Telegram (когда захотите)

1. https://my.telegram.org → API development tools → получить `api_id` и `api_hash`.
2. `./install.sh --tg`, затем `abook-tg setup` — введите api_id, api_hash, телефон и код, название канала.
3. В приложении у каждой книги появится «✈ в Telegram». Нескачанную книгу эта кнопка сначала скачает,
   проверит и склеит, потом отправит.

Секреты лежат в `~/abook/telegram.json` (chmod 600) и в репозиторий не попадают.

## 5. Как перенести свой вкус на другой компьютер

- **Автоматически:** шаг 6 «Другие компьютеры» на обоих компьютерах. Профили, анкеты, отзывы, память
  консультанта и реакции синхронизируются сами при запуске и через 20 секунд после изменений.
- **Каталог** на новом компьютере берётся из снимка (шаг 3), **аудио** у каждого компьютера своё.

## 6. Обновление

```bash
cd ~/projects/abook && git pull && ./install.sh
```
Затем закройте окно «Аудиотека» и откройте ярлык снова.

## 7. Где что лежит

| Путь | Что |
|---|---|
| `~/projects/abook` | код (этот репозиторий) |
| `~/abook/library.db` | база: каталог, профили, отзывы, память |
| `~/abook/config.json`, `llm.json` | папка библиотеки, выбранный ИИ |
| `<папка библиотеки>` | аудиокниги, `БИБЛИОТЕКА_ДЛЯ_ИИ.md` |
| `~/abook/sync` | клон `abook-data` (синхронизация) |
| `D:\VideoDownloader\Аудиотека-Obsidian` | зеркало памяти в Obsidian (кнопка «Obsidian ↗» в чате) |

## 8. Если что-то не так

- **Ярлык открывает старую версию:** закройте чёрное окно «Аудиотека» (это сервер) и откройте ярлык снова.
- **«CLI не найден»:** проверьте `which claude` / `which agy` в терминале WSL.
- **Не скачивается / только для спонсоров / не та книга:** кнопка «⚑» у записи. Запись больше не предлагается,
  можно сразу найти другую.
- **Мало места на C:** временные файлы и книги идут на диск из шага 2. В WSL лежат только код и база (≈ 0,5 ГБ).
