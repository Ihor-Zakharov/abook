# Промпт: ресёрч лучших идей из abook для другого проекта

Вставить в окно другого проекта как есть (при необходимости поправить первую строку «наш проект»).

---

Сделай ресёрч лучших идей из приложения abook (новая версия, 01.10.2026) и предложи, что и как перенести в НАШ
проект. Код abook не правь, только читай. Сначала план, потом ничего не внедряй без моего «да».

Где смотреть (читай выборочно, не целиком):
- `~/projects/abook-cosmos/docs/ПОИСК_И_ЧАТ.md` — архитектура: поиск в 4 уровня, память слоями, бюджет токенов.
- `~/projects/abook-cosmos/docs/NOTES.md` — разделы «Каталог», «Векторы», «Память», «Украинские источники».
- Код: `abook_links.py` (чат: потоковый ответ, `stream_claude`, `rec_action` — действие одной кнопкой с отложенным
  выполнением), `abook_memory.py` (журнал событий → факты → выборка MMR, забывание, резюме разговора, бюджет
  промпта), `abook_llm.py` (провайдер Claude / Antigravity под одним контрактом), `abook_vec.py` + `abook_rank.py`
  (гибридный поиск FTS + векторы, вкус из нескольких центров), `abook_catalog.py` (краулеры, склейка записей в
  произведения, отсев «только для спонсоров»), `abook_sync.py` (профили между компьютерами через приватный
  репозиторий), `abook_setup*.py` (мастер первого запуска).
- Интерфейс: `abook_find_ui.py` (чат во всю высоту, свёрнутая рельса, советы строками, реакции, жалоба «⚑»),
  `abook_ai_ui.py` (анкета: «по шагам / рассказать своими словами», быстрая оценка 1–10).
- Дизайн-кит, куда всё это уже вынесено как компоненты и правила: `~/projects/cosmos-kit` (v0.3.1) —
  `UX.md` §12–15, `references/lessons.md`, `src/blocks/chat.html`, `advice.html`, `dialog-rate.html`,
  `dialog-report.html`, `wizard-text.html`; демо `http://localhost:8810/demo/` и `/demo/chat.html`.

Что найти и оценить для нашего проекта:
1. **Дизайн и UX-решения**, которые подходят нашей теме: что взять как есть из кита, что переделать под наш
   сценарий. Для каждого — экран, где применить, и почему.
2. **Чат с ИИ:** потоковый вывод, «Остановить», «Другой ответ», правка последнего сообщения, инкогнито, карточки
   действий в ответе, одно действие до результата. Что из этого нужно нам и в каком виде.
3. **Память и экономия токенов:** слои памяти, консолидация дешёвой моделью, выборка под вопрос, резюме
   разговора, бюджет по разделам, кэшируемый префикс. Как правильно устроить у нас. Цифры abook: промпт
   86 → 26 тыс. символов, ответ $0.45 → $0.16.
4. **Инфраструктура:** провайдер ИИ на выбор, мастер первого запуска, синхронизация через приватный репозиторий,
   жалоба на источник с немедленным действием.

Формат результата: таблица «идея → где в abook (файл:функция) → как у нас → польза → трудоёмкость (S/M/L) →
риск», отсортированная по пользе к трудоёмкости; топ-5 с конкретным планом внедрения; что брать НЕ стоит
и почему. Учитывай правила нашего проекта (AGENTS.md / CLAUDE.md) и мои UX-предпочтения из памяти.
