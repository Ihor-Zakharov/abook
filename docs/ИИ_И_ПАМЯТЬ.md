# ИИ-окружение и память abook — гайд

Как устроены ИИ, поиск и память в abook и как с этим работать. Подробности по коду — `docs/NOTES.md`,
архитектура и цифры — `docs/ПОИСК_И_ЧАТ.md`.

## 1. Провайдеры ИИ: Claude или Antigravity

Все вызовы ИИ идут через две точки — `abook_find.run_claude` (ответ JSON по схеме) и `abook_links.stream_claude`
(потоковый ответ чата). Обе в начале спрашивают `abook_llm.provider()` и, если выбран Antigravity, отдают работу
`abook_llm.run` с тем же контрактом: `(data | None, meta, error | None)`, те же фазы и события для интерфейса, та
же отмена.

| Уровень | Claude Code (`claude -p`) | Antigravity (`agy`) | Где используется |
|---|---|---|---|
| умный | Opus | Gemini 3.1 Pro (High) | консультант, подбор топ-5, поиск в сети |
| средний | Sonnet | Gemini 3.8 Flash (High) | анкета из рассказа, признаки «карты связей» |
| быстрый | Haiku | Gemini 3.8 Flash (Low) | вопросы анкеты, сводка памяти, резюме разговора, другие названия книги |

- Выбор — переключатель в шапке чата или в «Настройке»; хранится в `~/abook/llm.json`, `ABOOK_LLM=claude|agy`
  перекрывает. Модели Antigravity: `ABOOK_AGY_MODEL_SMART|_MID|_FAST`.
- Длинный промпт у `agy` передаётся файлом в рабочем каталоге (аргумент командной строки в Linux ≤ 128 КБ).
- ИИ не получает ни файлов, ни shell: у Claude — только WebSearch/WebFetch там, где нужно, у `agy` — чтение
  файла задания.
- Цена и токены каждого вызова пишутся в `meta` сообщения и видны в «Статистике».

## 2. Поиск: от дешёвого к дорогому

1. **Библиотека** — `items`, мгновенно.
2. **Каталог интернета** — `src_items` (≈ 180 тыс. записей: YouTube-каналы чтецов, knigavuhe, akniga, archive.org,
   4read, 20 украинских каналов), склеены в `works` (≈ 110 тыс. произведений). Полнотекстовый индекс trigram,
   ответ 5–40 мс. Записи «только для спонсоров» отсеяны, жалобы «⚑» убирают запись сразу.
3. **Смысловой поиск** — векторы multilingual-e5-small (демон `abook_vec.py` в `~/abook/.venv-vec`), слияние
   с текстовым поиском (RRF).
4. **Переписывание запроса** — если по словам ничего сильного («Фундация» вместо «Основание»), быстрая модель
   один раз даёт другие названия; кэш навсегда (`query_alias`), повтор — без ИИ.
5. **Поиск в сети** — площадки напрямую + ИИ с WebSearch, каждая запись проверяется yt-dlp без скачивания.

## 3. Память: в промпт попадает выборка, а не всё

| Слой | Таблица | Как пишется | Что попадает к ИИ |
|---|---|---|---|
| События | `mem_events` | каждая реплика, 👍/👎/«читал», оценка, жалоба — без ИИ | никогда целиком |
| Факты | `consultant_memory` (+ уверенность, вес, вектор) | сводка Haiku раз в 8 событий: добавить / уточнить / слить / удалить; «от вас» не трогается | 8–12 фактов под вопрос: ядро + похожие по смыслу, без повторов (MMR) |
| Вкус | `rec_feedback`, профиль ИИ, анкета | теги «любите/избегать» — центры вкуса, реакции правят сразу | не текстом: порядок кандидатов |
| Разговор | `chat_sessions.summary` | старые реплики сворачиваются в резюме | резюме + 6 последних реплик |

- **Забывание:** вес факта = уверенность × 0,5^(возраст / период полураспада): вкус — год, «сейчас хочу
  короткое» — две недели. Поправленное вами не стареет. Автофактов не больше 80.
- **Бюджет:** у каждого раздела промпта свой потолок (`abook_memory.BUDGET`); стабильное (правила, профиль) идёт
  первым — его кэширует провайдер, изменчивое (кандидаты, разговор, сообщение) — последним. Разбивка пишется в
  `meta.budget`.
- **Итог:** промпт консультанта 86 → ≈ 17–20 тыс. символов, ответ ≈ $0.45 → ≈ $0.12.
- **Инкогнито:** только этот разговор и каталог; ничего не пишется.
- **Obsidian:** кнопка «Obsidian ↗» в чате выгружает профиль, память, книги и разговоры в vault со связями
  `[[…]]`; новые строки в `Память.md` забираются обратно как факты «от вас».

## 4. Что где настраивать

| Что | Где |
|---|---|
| провайдер ИИ | шапка чата, «Настройка», `~/abook/llm.json` |
| языки советов | анкета → «Как слушаете»: русский и украинский на равных, английский немного (по умолчанию) |
| папка библиотеки | «Настройка», `~/abook/config.json` |
| источники каталога | `~/abook/sources.json`; обход — `python3 abook_catalog.py crawl` |
| бюджет промпта, полураспад, частота сводки | `abook_memory.py`: `BUDGET`, `HALF_LIFE`, `CONSOLIDATE_EVERY` |
