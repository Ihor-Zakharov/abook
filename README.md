# abook — личная аудиотека с ИИ-консультантом

Веб-приложение для своей коллекции аудиокниг: поиск по каталогу из ≈ 180 тыс. записей со всего интернета,
ссылка на источник, скачивание полной записи с проверкой частей, склейкой и проверкой целостности, отправка
в Telegram одной кнопкой, отзывы и статистика прослушанного, консультант-чат, который помнит ваш вкус.

Интерфейс — на дизайн-ките [cosmos-kit](https://github.com/Ihor-Zakharov/cosmos-kit) (тёмная тема «чёрная дыра»,
оформление «Серая» или «Золотистая»).

## Для агента: как пользоваться этим репозиторием как базой знаний

Здесь собран рабочий опыт одного приложения на ИИ: чат-консультант, память, экономия токенов, поиск по большому
каталогу, краулеры, провайдеры ИИ, UX на дизайн-ките. Его подключают к другим проектам как справочник.

1. **Сначала ищи ответ здесь**, в интернет — только за тем, чего нет, или если важна версия библиотеки.
2. **Не читай документы целиком** — они длинные. Оглавление: `grep -n "^#" docs/NOTES.md`, потом нужный
   диапазон строк. Код — по таблице «Вопрос → где ответ» ниже, функция за функцией.
3. **Цифры и решения проверены на живых данных** (даты в заметках). Модели, цены и версии CLI устаревают —
   перед переносом сверь их.
4. **Переносишь идею — переноси и её грабли**: они записаны рядом с решением («Не проверено», «Почему так»).

### Вопрос → где ответ

| Вопрос | Где |
|---|---|
| Что используется, грабли и когда что уместно | `docs/ДЛЯ_АГЕНТОВ.md` |
| Какую память выбрать (Mem0, Letta, Zep, LangMem, своя) и общие советы | `docs/ПАМЯТЬ_РЕСЁРЧ.md` |
| Как устроить память ИИ-ассистента без раздувания контекста | `docs/ИИ_И_ПАМЯТЬ.md` §3, `abook_memory.py` (журнал → факты → выборка MMR → бюджет) |
| Как сократить токены промпта в 4 раза | `docs/ИИ_И_ПАМЯТЬ.md` §3, `abook_links.py: build_chat_prompt`, `abook_memory.fit` |
| Как подключить Claude Code и Antigravity под одним контрактом | `abook_llm.py`, `docs/ИИ_И_ПАМЯТЬ.md` §1 |
| Потоковый ответ модели в веб-чат (stream-json, разделитель JSON) | `abook_links.py: stream_claude`, `live_payload`; фронт — `abook_find_ui.py: fdLiveTick` |
| Чат как в браузерных ИИ: остановить, другой ответ, правка, инкогнито | `abook_find_ui.py` (блок «Чат»), кит: `cosmos-kit/src/blocks/chat.html` |
| Действие «одной кнопкой» с отложенным выполнением | `abook_links.py: rec_action`, `_act_worker` |
| Поиск по 180 тыс. записям за миллисекунды (FTS5 trigram, склейка в произведения) | `abook_catalog.py: _fts, search_works, rebuild_works`, `docs/NOTES.md` «Широкий каталог» |
| Гибридный поиск (FTS + векторы, RRF) и модель вкуса | `abook_vec.py`, `abook_rank.py`, `docs/NOTES.md` «Векторы», «Модель вкуса» |
| Переписывание запроса (другие названия) с вечным кэшем | `abook_find.py: query_variants` |
| Вежливые краулеры, отсев «только для спонсоров», проверка полноты без скачивания | `abook_catalog.py`, `abook_find.py: probe, assess` |
| Жалоба на источник с немедленным действием | `abook_links.py: report_source` |
| Синхронизация личных данных через приватный git-репозиторий | `abook_sync.py` |
| Зеркало памяти в Obsidian | `abook_vault.py` |
| UX-правила, проверенные на пользователе | кит: `cosmos-kit/UX.md` §12–15, `references/lessons.md` |

## Модули

| Файл | Что делает |
|---|---|
| `abook` | скачивание, склейка, проверка, база, веб-сервер `abook review` |
| `abook_find.py`, `abook_find_ui.py` | поиск, загрузки, чат, интерфейс «Найти» и «Чат» |
| `abook_catalog.py` | каталог источников: краулеры, произведения, отсев «только для спонсоров» |
| `abook_vec.py`, `abook_rank.py` | векторы, гибридный поиск, модель вкуса и ранжирование |
| `abook_links.py`, `abook_memory.py` | консультант, карта связей, память слоями, бюджет промпта |
| `abook_llm.py` | провайдер ИИ: Claude Code или Antigravity |
| `abook_ai.py`, `abook_ai_ui.py` | профили, анкета, профиль вкуса от ИИ |
| `abook_tg.py`, `abook-tg` | отправка в Telegram |
| `abook_setup*.py`, `abook_sync.py`, `abook_vault.py` | настройка, синхронизация профилей, зеркало в Obsidian |
